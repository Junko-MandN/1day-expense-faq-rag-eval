# C方式の追加分析：不一致の原因調査

評価で期待回答と一致しなかった2問（Q5、Q6）について、Cに実際に渡された規程行と各方式の回答を確認し、原因を分析した。

## 確認方法

- C方式で検索された規程行（検索キーワード、検索行数、行の内容）を、そのまま出力して確認した（`inspect_result.txt`）。
- 回答は、保存済みの実行結果を確認した。
- 今回の分析は、保存済みの検索結果と回答に基づくものであり、改善後の再実験は実施していない。

## Q5：宿泊費の上限超過と事前承認

**質問：** 1泊15,000円のホテルは、事前に所属部門長の承認を得れば精算できますか？

**期待回答：** 予約前に所属部門長の承認を得ていれば、宿泊費の上限を超える宿泊が必要な場合の例外として精算できます。

### 検索結果

- 検索キーワード：宿泊費、精算、ホテル
- 検索行数：11行
- うち、宿泊費の上限と承認に直接関わる行は、次の3行程度（目視による概算）。
  - `## 4. 宿泊費`
  - 国内出張の宿泊費は、1泊あたり12,000円を上限とする。
  - 承認を得ずに上限を超えた場合、原則として超過分は精算できない。
- 規程にある次の行は、検索されなかった。
  - 上限を超える宿泊が必要な場合は、予約前に所属部門長の承認を得る。

この行は「宿泊が必要な場合」と書かれており、キーワードの「宿泊費」「精算」「ホテル」のいずれとも一致しない。

### 各方式の回答

- **B（規程全文）：** 「はい、1泊15,000円のホテルは、事前に所属部門長の承認を得れば精算できます。（第4章 宿泊費の規定による）」
- **C（簡易RAG）：** 「規程によると、国内出張の宿泊費は1泊あたり12,000円を上限とし、承認を得ずに上限を超えた場合は超過分を原則精算できないとあります。しかし、『事前に所属部門長の承認を得れば』については規程に明記されていません。」

### 分析

2つの要因が重なっている。

| 要因 | 内容 |
|---|---|
| ① 検索漏れ | 承認の行が、キーワードの不一致でCに渡されなかった |
| ② 規程の曖昧さ | 規程全体にも、承認を得た場合に超過分を精算できるという明記や、承認の基準はない |

- Cは、渡された行の範囲では妥当に回答している。ただし、「渡された行にない」ことを「規程に明記されていない」と表現しており、実際の規程には承認の行がある点は反映できていない。
- Bは、承認後の精算可否が第4章に明記されていないにもかかわらず、第4章を根拠に、精算できると断定した。
- 期待回答も、規程から読み取れる結論ではあるが、明記された内容ではない。期待回答の設計を見直す必要がある。

### 評価の記録について

`evaluation.csv` のC・Q5の備考は、当初「規程の曖昧さを正しく指摘」としていたが、検索ログの確認後に「検索漏れを含む」と修正した。点数は変更していない。

## Q6：新幹線の領収書を紛失した場合の対応

**質問：** 新幹線の領収書を紛失したら、どうすればいいですか？

**期待回答：** 経理担当者に相談してください。領収書を紛失しただけで精算が自動的に承認されることはありません。

### 検索結果

- 検索キーワード：証憑、領収書
- 検索行数：5行（すべて領収書・証憑に関する行）
- 次の2行が、両方とも検索結果に含まれていた。
  - 領収書を紛失した場合は、経理担当者に相談する。
  - 領収書を紛失したことだけを理由に、精算が自動的に承認されることはない。

### 回答

Cは相談先（経理担当者）を回答したが、自動的に承認されないという注意点を回答に含めなかった（Bは両方を回答した）。

### 分析

必要な情報は検索結果に含まれていたため、検索よりも、回答生成の段階で重要な注意点が省略された可能性がある。ただし、原因を確定するには、追加実験が必要である。

## 検索全般について

- 「精算」というキーワードが、多くの行に一致する。Q5では、11行のうち、質問に直接関わる行は3行程度だった。
- 一方、キーワードに表記が一致しない行は、必要でも取得できない（Q5の承認の行）。
- 検索キーワードの設定が、取得の過不足の両方に影響している。

## 今回の調査から得られた学び

- 期待回答との不一致を、すべて検索の失敗、またはすべてモデルの問題として扱うことはできない。
- 検索結果、元データの明確さ、AIの回答を分けて確認することで、原因を切り分けられる。
- 検索の漏れは、モデルが保留したように見える回答として現れる。実際に渡した規程行を確認するまで、原因は分からない。
- 検索で必要な情報を取得できていても、回答に重要な条件が反映されない場合がある（Q6）。
- 規程自体が曖昧な場合は、AIに推測させるのではなく、業務担当者によるルールの明確化が必要である。

## 未検証のこと

- キーワードの見直し（例：「宿泊費」を「宿泊」に、「承認」を追加）で、Q5が改善するか。
- Q6の省略が、同じ質問の繰り返しでも再現するか。また、「重要な注意点や条件も省略せずに回答する」という指示で減るか。
- 上記の効果を確かめるには、今回の10問とは別の質問セットが必要である。同じ10問で調整すると、結果を見てから直したことになる。
